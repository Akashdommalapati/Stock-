# Godown Stock & Sales Manager - Frontend

React + Vite + Tailwind CSS frontend for Godown Stock & Sales Manager.

## Tech Stack
- React 18, Vite
- Tailwind CSS with custom beverage flavor theme
- Lucide React icons
- Recharts analytics
- React Router DOM

## Setup & Run
```bash
npm install
npm run dev      # Runs frontend on http://localhost:5173
npm run build    # Produces production bundle in dist/
```

## Environment (.env)
```env
VITE_API_URL=http://localhost:5000/api
```
